# Abdullah Al Moneem — Portfolio

Personal portfolio website for Abdullah Al Moneem, a full-stack developer based in Bangladesh.

**Live site:** [moneem.pro.bd](https://moneem.pro.bd)

## About

The site highlights my skills, projects, hackathon achievements, and contact links. It is a lightweight, responsive static website built with vanilla HTML, CSS, and JavaScript.

## Run locally

Serve the project with any local web server (the site loads content from a JSON file):

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Customize

- Update portfolio content, projects, and links in `data/portfolio.json`.
- Edit styles in the `css/` directory.
- Update site structure and metadata in `index.html`.
- Place images in `assets/images/`.

## Project structure

```text
├── index.html          # Page structure and SEO metadata
├── css/                # Site styles
├── js/                 # Rendering and interaction scripts
├── data/portfolio.json # Portfolio content
└── assets/             # Images, icons, and resume files
```
