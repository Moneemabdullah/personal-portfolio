About Me

I'm a CSE student at BAIUST, Bangladesh, building full-stack web applications — React and Next.js on the frontend, Node.js/Express and PostgreSQL/MongoDB on the backend. I enjoy building systems that are well-structured end-to-end, not just working code.

My projects span a full-stack freelancing marketplace (OutSourceX), a food ordering platform, and an IoT-integrated smart agriculture system — each built with proper authentication, role-based access, and REST API integration across both the client and server.

Outside of coding, I do competitive programming (300+ problems solved) and have placed in six university-level hackathons.
